# 模块 02：交易统计与可视化

日期：2026-10-21。依赖已完成的数据导入与清洗模块。

## 功能

按日期（完整包含起止日）和国家筛选所有销售指标、五类图表、客户明细及 ZIP 分析表。空国家集合表示不选择任何国家。国家选项包含销售与取消/退货候选的并集，没有销售的退货国家仍可查看候选金额。

订单按 InvoiceNo 去重；可识别客户与复购分母不包含匿名客户。复购指本次筛选内至少两笔订单。销售额先用 Python 整数求和 AmountCents 再换算英镑；数量不截断小数。缺月份补零，商品同编码不同名称按最常出现的名称展示，同频时按字典序稳定选择。

订单跨月、国家、时段时可能在多个分组出现，不能将这些分组订单数直接相加当作全局订单数。购买时段来自交易记录，不是访问日志。
