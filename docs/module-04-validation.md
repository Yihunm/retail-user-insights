# 模块 04：用户聚类分析

日期：2026-10-26。分支：codex/retail-analysis-system。

## 输入与算法

使用RFM模块按参考日和观察窗口提取的可识别客户特征：最近购买间隔、订单数、消费金额、购买数量、平均订单金额。匿名和窗口外客户不参与。编号、RFM评分和RFM规则类型不作为训练特征。

处理顺序：log1p对数变换 → 删除无方差列 → 标准化 → K-Means。固定随机种子42、初始化20次、Lloyd算法，按客户编号排序后训练，重复运行和输入行顺序变化可复现。

候选2–8组，并受客户数和变换后不同特征向量数约束。自动推荐选择最高可用轮廓系数，平局选较小组数；也可在页面手动选择。不能形成有效群体或输入不足时给出提示，不伪造评价分数。

轮廓系数默认最多评价2,000人，样本多时先确保每个群体至少一人，再无放回抽取其余样本；记录实际评价人数、是否抽样和实际群体数。无定义的系数为空。该评价是抽样估计，不是分类准确率。

PCA在完整变换空间上拟合，仅用于二维显示；不使用二维坐标训练K-Means。仅剩一项有效特征时第二坐标为0。群体编号不表示价值排名，改变窗口或组数可能改变编号。

## 页面与保存

- 表单设置参考日、全部历史/90天/180天和自动/手动数量，明确点击按钮才训练。
- 聚类数量比较：轮廓系数与簇内平方和曲线、候选评价表。
- 群体画像：人数、占比、精确消费总额及各项原始指标均值/中位数；相同群体在不同图表中使用相同颜色。
- 二维分布：按群体着色的PCA散点，显示解释方差比例与客户原始特征。
- 客户明细：群体和编号筛选，预览200人，导出完整匹配结果。筛选不重训，群体画像和数量评价继续基于模型总体。
- 切页恢复模型和筛选，更换数据版本清除旧结果。固定训练提示位置，避免搜索后跳回第一个标签页。
- 每次训练保存model.joblib、完整客户/画像/评价CSV、metadata.json，并登记SQLite cluster_runs；只使用项目生成的可信本地模型。
- ZIP为中文客户明细、模型总体画像、数量评价和筛选说明，明确区分模型总体和筛选结果，保留整数分金额。

自动推荐2组：群体1共1,810人，消费£7,740,530.63；群体2共2,524人，消费£996,697.01。人数合计4,334，金额合计873,722,764整数分，与RFM总体一致。该结果仅对应本次数据、特征和参数，不保证其他数据也应分2组。

## 验证

- 核心28项测试：复现、输入顺序不变、输入不被修改、参数/缺失/负数/常量/重复编号校验、有效候选、自动选择、稀有簇抽样、单维PCA、整数分画像和Pipeline保存复载。
- 页面与导出5项测试：显式训练、搜索不重训、切页恢复、小样本提示、数据版本失效、群体颜色一致、ZIP范围及持久化。
- 全套132项测试（警告作为错误）和Ruff检查作为提交验收。
- Chromium实测：手动4组训练、全量人数、PCA、客户搜索保持标签页且不新增模型、下载ZIP核对单个客户与全体画像、表单改90天不立即训练、再点击后更新2,885人。

本模块仅为无监督客户群体发现。没有真实类别标签，不声明分类准确率，也不自动发送营销信息。复购与流失预测留待后续独立模块。
