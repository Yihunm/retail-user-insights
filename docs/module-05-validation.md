# 模块05：复购与流失预测验收

## 目标与数据边界

仅使用有效交易中的已识别客户。总体为截点前90天内有购买的客户，不能据此推断从未购买的访问用户。没有浏览、收藏、加购特征。

- 复购正例：未来30天内有有效购买。
- 未购买风险正例：未来60天内没有有效购买；不表示永久流失。
- 特征区间 `[T-90天,T)`，标签区间 `[T,T+预测天数)`，均左闭右开。
- 仅构建历史及未来标签完整可见的样本，排除数据首尾不完整日。当前完整日范围为2010-12-02至2011-12-09（不含右端）。

15项特征包括最近购买间隔、近7/30/90天订单数和金额、90天数量/不同商品数/活跃天数、平均与最大订单金额、平均购买间隔及缺失标记、窗口内购买跨度。客户编号不参与训练。金额先按整数分精确汇总，再转换为模型输入。

## 时间划分与模型选择

| 数据划分 | 截点 | 样本数 |
| --- | --- | ---: |
| 训练 | 2011-03-02、04-01、05-01、06-01 | 7,285 |
| 验证 | 2011-08-01 | 2,019 |
| 最终测试 | 2011-10-01 | 2,145 |

合计11,449条“客户×截点”样本，同一客户可出现在不同截点；这是已有客户的时间外推实验，不代表新客户泛化评价。

候选包括先验基线，以及逻辑回归、决策树、随机森林分别搭配不处理、欠采样、随机过采样、SMOTE和类别权重，共16种方案。非基线每种尝试两组参数，训练内部前向验证使用“3月→5月”“3/4月→6月”。标签结束时间须不晚于后续验证截点。

填补、标准化与采样仅在各训练折内拟合。验证和测试保持原始分布。SMOTE只生成训练特征向量，不伪造真实交易；少数类不足时跳过并说明。训练正例比例约为复购31.6%、未购买51.7%，并非所有任务都严重不平衡。

按验证集平均精确率（AP）优先、F1次之选择模型；阈值最大化验证F1，同分选择较高阈值。AP使用平均精确率定义，并非梯形积分PR-AUC。最终测试仅评价选定方案，选择后不合并验证集重新训练。测试结果不参与调参或阈值选择。

## 本地真实数据结果

数据版本：`1507a2fad9a91c571147ca49f7252e0c377e2ef69fe015827318e0f522545d8c`，随机种子42。

| 项目 | 30天复购 | 60天未购买风险 |
| --- | ---: | ---: |
| 选定模型 | 随机森林 + SMOTE | 随机森林 + 随机过采样 |
| 阈值 | 0.497673 | 0.303196 |
| 验证AP | 0.617009 | 0.656896 |
| 测试AP | 0.581628 | 0.543489 |
| 测试准确率 | 0.667599 | 0.565501 |
| 测试精确率 | 0.528075 | 0.482944 |
| 测试召回率 | 0.523179 | 0.922286 |
| 测试F1 | 0.525615 | 0.633936 |
| 测试ROC-AUC | 0.675411 | 0.678646 |
| 测试正例比例（AP无区分参考） | 0.351981 | 0.407925 |
| 本机训练耗时 | 约30秒 | 约31秒 |

未购买风险方案的召回率较高，但精确率不足0.5，存在较多误报，不应直接等同于可投入运营的客户流失判定。两项分数均未校准，不解释为精确概率；指标只描述当前数据、标签和时间划分。最新截点之后的真实结果尚不可见。

## 保存、重放与页面

模型、指标、曲线、特征重要性、样本及元数据存入本地 `artifacts/prediction/<训练编号>/`，SQLite登记训练记录。全部保存成功后才写入带元数据SHA256的 `COMPLETE.json`。不完整或损坏记录不会作为可用模型列出；模型反序列化损坏给出可读错误。

加载时校验任务、数据版本、特征顺序和特征版本。推断日期不能早于验证标签完整可见之日：复购2011-08-31，未购买2011-09-30。

本次两个模型分别重放2011-10-01的2,145名客户，分数与保存的最终测试结果在1e-12容差内一致。最新截点2011-12-10可预测2,885名客户，不包含真实标签。

页面支持分别训练、已保存模型加载、中文对比与曲线、日期选择、客户搜索和ZIP下载。导出含任务、预测窗口、模型/数据/训练编号、阈值及未校准说明。切换模型清空旧客户预测，加载与搜索不会产生新训练记录。

## 验证方法

自动化测试覆盖未来信息隔离、完整窗口、正负标签、金额与特征边界、前向训练折、训练内采样、验证阈值、最终测试隔离、版本校验、损坏模型与不完整记录、中文导出和页面状态。完整测试套件200项；同时运行Ruff与Git差异空白检查。

真实浏览器验收两个任务的模型加载、2,885名客户推断、客户12347筛选及ZIP内容，核对任务、窗口、阈值标签、不包含真实结果、不重新训练及切换模型清理状态。另独立运行命令行样本构建，核对11,449条样本。

复现命令与使用步骤见仓库README。模型和数据均为本地产物，不提交Git；其他设备应先导入同一数据，再分别训练两项任务。
